# Памятка по разметке

Размечается не итоговая сумма листа, а **каждый размер D1, D2, D3…**. Для обучения важнее 30–50 полностью проверенных разных листов, чем 300 листов с непроверенным черновиком.

## Где смотреть

Для большого PDF разметка сейчас здесь:

`output\Изометрии_без_API\`

- `overlays\*_ids.png` — исходный лист с метками D1, D2…
- `markup\*.png` — цветной результат: что вошло в сумму;
- `llm_raw\sheet_XX.json` — решение по каждому D;
- `overlays\*_hits.json` — координаты и текст рядом с размером; руками этот файл не править;
- `lengths.xlsx` и `report.html` — суммы по листам.

Удобнее размечать в приложении:

```powershell
python pipeline.py annotate
```

Или просто `python app.py` → вкладка **Обучение** / **Результаты**.

Открыть вкладку **Результаты**, выбрать нужный PDF, нажать на строку листа. Клик по цифре или строке справа переключает:

`в сумму → глянуть → вложенный → не длина`

После первой ручной правки лист получает `"locked": true`: API и автоправка его больше не перезапишут.

## Четыре решения

### `include` — в сумму

Самостоятельный участок трубы или ветки по оси. Включать короткие отводы, вертикали и размеры рядом с координатами X/Y/Z.

Примеры: 34, 320 рядом с X, 1383 рядом с Z+, отдельные прогоны 2000 и 2400.

### `exclude_nested` — вложенный / двойной счёт

Размер описывает тот же участок, который уже полностью покрыт другим выбранным размером.

- 916 внутри 1950;
- 300 внутри 840;
- LT или `overall_pair` поверх уже выбранного участка;
- цепочка полностью покрывает общий размер — выбрать либо цепочку, либо общий, но не оба.

Особое правило Н.О.: если цепочка расстояний между опорами **не дошла до конца участка**, брать полный размер Н.О., а куски этой цепочки не брать.

Пример:

`24100`, а цепочка `4100+6000+6000+6000=22100`. Не хватает 2000, значит берём 24100 целиком.

### `not_length` — не длина трубы

Координаты X/Y/Z, DN, номер позиции, штурвал, **толщина** изоляции внутри плашки, значение в спецификации / «Длины отрезков» / штампе, повторяющийся размер опоры.

Плашка «ИЗОЛЯЦИЯ: H / ОБОГРЕВ: E5» — это тип, не толщина. Размеры на оси рядом с ней (излом 123+244+123) входят в сумму.

Отверстия, врезка и съёмный участок — это труба, `include`.

Важно: число рядом с `Z+ 37329` может быть нормальной длиной. Координата — 37329, а 1383 рядом с ней — длина.

### `ambiguous` — глянуть

Использовать только когда по листу действительно нельзя уверенно решить. Перед обучением желательно открыть такие размеры и заменить на один из трёх точных классов.

## Как проверить лист

1. Начать от ПОДКЛЮЧЕНИЕ/СМ и пройти всю ось трубы.
2. Отдельно пройти каждую ветку.
3. Для каждого прямого участка выбрать одно представление: полный размер или полную цепочку.
4. Проверить, нет ли дырки между последней опорой и концом участка.
5. Убедиться, что один физический кусок не взят дважды.
6. Выкинуть штурвалы, **толщину** изоляции внутри плашки, координаты, DN, позиции и числа из штампа/спецификации/«Длины отрезков». Размеры на оси рядом с типом изоляции, отверстия и съёмный участок оставить.
7. Сверить зелёную формулу сверху картинки и итог листа.

## Как открыть JSON

В Cursor/PyCharm: открыть папку проекта и файл, например:

`output\Изометрии_без_API\llm_raw\sheet_08.json`

Из PowerShell в Блокноте:

```powershell
notepad "output\Изометрии_без_API\llm_raw\sheet_08.json"
```

У каждого элемента меняется только `decision`. Допустимы:

```json
{"id":"D8","decision":"include","role":"main","reason":"руками"}
```

Если JSON правился вручную, поставить наверху `"locked": true`. После ручного JSON нужно пересчитать отчёт через приложение или режим replay; безопаснее править кликами в приложении.

## Единый конвейер

Двойной клик по `конвейер_обучения.bat` открывает меню. В приложении то же на вкладке **Обучение**.

То же из PowerShell:

```powershell
python pipeline.py prepare "C:\путь\Изометрии.pdf"
python pipeline.py annotate
python pipeline.py audit
python pipeline.py train
```

Последовательность: подготовить черновик → исправить листы кликами → аудит → обучение. Метрики лежат в `models\training_report.json`, проверка разметки — в `output\label_audit.json`.
