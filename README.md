# длина по изометриям — локальная модель

Программа открывает pdf с изометриями и считает, сколько миллиметров трубы на листе. Ветки тоже. До «ПОДКЛЮЧЕНИЕ» / «СМ», один кусок один раз.

Ключ API не нужен. Интернет не нужен. Cursor не нужен. На ноуте считается на процессоре, видеокарта только если учить заново.

Цифры с чертежа читает PyMuPDF (это текст в pdf, OCR не ставил). Дальше CatBoost говорит по каждой цифре: длина, вложенное или вообще не труба. Складывает python. Модель числом «итог листа» не выдаёт — только класс. Зелёное в сумме, фиолетовое внутри уже взятого участка, серое не длина.

## что умеет

- Берёт ось и ответвления, короткие отводы тоже (34 мм нормальная длина).
- Не берёт координаты X/Y/Z, DN, кружки позиций, штурвал, толщину из плашки изоляции, штамп, спецификацию и таблицу «Длины отрезков».
- Вложенное не плюсует. В примере задания 916 сидит в 1950, 300 в 840 — их нет в сумме. Лист 7 = 4306 мм.
- Н.О.: если цепочка опор не дошла до конца участка — беру полный размер, куски выкидываю. Лист 8 = 48625 (23525+1000+24100), а не 44950.
- Длинный прогон с размерной линией и опорами внутри — это основная длина, не «вложенный габарит».
- В окне можно кликнуть по цифре и поправить. После правки лист закрывается (`locked`), программа его больше не перетирает.

## как запустить на ноуте

Python 3.10+. GPU не обязателен.

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Или двойной клик `запуск.bat`. Браузер: http://127.0.0.1:8765

Вкладка Расчёт → pdf → Рассчитать. Если свой файл не выбрал, возьмёт `data\02_Изометрии_10_листов.pdf`.

`.env` можно не делать. Образец `.env.example` пустой, ключей там нет.

## как это внутри устроено

1. `extract.py` вытаскивает целые числа с листа, сразу выкидывает координаты, DN, штамп, спецификацию.
2. `vector_geometry.py` собирает размерные линии из векторных штрихов pdf (`page.get_drawings()`).
3. `relations.py` смотрит, кто внутри кого: опора внутри прогона, габарит поверх кусков.
4. `local_model.py` + `models\iso_clf.pkl` — CatBoost, 5 моделей, голосуют argmax.
5. `guards.py` добивает то, что модель путает каждый раз: штурвал, Н.О., вложенность.
6. Сумма только `include`. Excel и html пишет `report.py`.

Училась на GPU (RTX 3070, CUDA, CatBoost 1.2.10). Н

Обучение: листы 1–277 файла Изометрии.pdf. Тесты 278–307 в train не входят, в отчёте пересечение пустое.

Переучить (не обязательно, и без NVIDIA не выйдет):

```
python pipeline.py prepare "C:\путь\Изометрии.pdf"
python pipeline.py annotate
python pipeline.py train
```

## метрики — что значат цифры

Берутся из `models\training_report.html`. Это не «насколько верна сумма листа». Это насколько модель угадала **класс** цифры. Сумму потом правят гарды. Поэтому F1 высокий, а сырая ошибка суммы листа всё равно бывает большой — без правил геометрию не вытянуть.

На обучении (225 листов, 3075 размеров): accuracy 0.985, macro-F1 0.964.  
На проверке внутри train (50 листов, 675 размеров): accuracy 0.979, macro-F1 0.960.

**accuracy** — доля цифр с правильным классом. 0.979 ≈ 98 из 100.

**precision** — из тех, кого записали в класс, сколько правда этого класса. Если precision у «не длина» высокий, модель редко орёт «мусор» на нормальную трубу.

**recall** — из всех настоящих примеров класса сколько нашла. Recall у «не длина» ниже (0.88 на val): часть штурвалов и координат модель сначала тащит в сумму, гарды снимают.

**F1** — среднее между precision и recall. Одно число, чтобы не хвастаться только accuracy.

**macro-F1** — F1 трёх классов поровну. Редкий класс «не длина» весит столько же, сколько куча include. Это честнее, чем смотреть только на зелёные.

**weighted-F1** — то же, но редкие классы весят меньше. Почти совпадает с accuracy, потому что include больше всего.

**overfit_gap** — насколько train F1 выше val. У меня 0.004, порог «ок» 0.05. Модель не зазубрила 277 листов наизусть.

**MAE суммы листа** — средняя ошибка итога листа в мм, если сложить как сказала модель, без гардов. Train ~232 мм, val ~977 мм. Медиана 0: на половине листов и так совпало. Хвост до 14 тысяч — один кривой габарит ломает лист. Поэтому поверх бустинга правила.

**деревья** — 498 / 179 / 421 / 275 / 318 в пяти CatBoost. Раньше чем на 20 деревьях модель не сохраняю, это был бы недоученный пень.

**holdout_check** — тесты 278–307 не пересеклись с train. ok.

Порог «глянуть, если не уверена» на val не использую. При 0.9 уверенности покрытие падало, в сумме дыры. В бою argmax: каждый D получает класс.
